# 每日所学

一个个人学习笔记网站。随手记下当天所学，之后按日期回顾，或用记得的词找回原文。

## v0.1 MVP

- 输入框支持直接打字和语音转写。转写后的文字可以编辑，确认后保存。标题选填。
- 学习日期默认是今天，支持补记。时间线按日期倒序排列，同一天的笔记自动归在一起。
- 搜索标题和正文，展示匹配片段和日期。点击结果可以查看或编辑笔记。
- 使用单人账号和服务端存储，在手机记录、电脑查阅。只保存确认后的文本。

验收流程：在手机口述并修正一条笔记，保存后在电脑用同一账号登录，分别通过日期和正文关键词找到这条记录。

## v0.2 内容分类

依据笔记内容生成可编辑的主题标签。同一条笔记可以属于多个主题，仍可按日期查看。
